# 22 — Resume Claims Cross-Examination & Verification

## 1. Resume Claim Verification Matrix

| Resume Claim / Bullet Point | Technical Meaning & Implementation Location | Potential Interview Question | How to Defend Confidently |
| :--- | :--- | :--- | :--- |
| *"Built an autonomous multi-agent platform with LangGraph"* | Implemented a cyclic `StateGraph` in `src/lib/agent/builder.ts` with `agent`, `tools`, and `tool_approval` nodes. | *"Why did you use LangGraph instead of a simple OpenAI API call?"* | Explain that standard API calls cannot handle conditional looping, dynamic tool retries, human review interrupts, and checkpointed state resumption. |
| *"Implemented persistent memory using PostgreSQL checkpointer"* | Used `@langchain/langgraph-checkpoint-postgres` in `src/lib/agent/memory.ts` storing serialized message channels by thread. | *"How does the checkpointer store complex message objects in Postgres?"* | Explain that it writes serialized state snapshots and diffs into `checkpoint_blobs` and `checkpoints` tables indexed by `thread_id`. |
| *"Integrated Model Context Protocol (MCP) for tool execution"* | Implemented STDIO and HTTP transports in `src/lib/mcp/` and converted discovered tools to `DynamicTool` instances. | *"What is MCP and how does it differ from standard REST APIs?"* | Explain that MCP is a standardized JSON-RPC protocol over STDIO/HTTP that allows agents to discover schemas and invoke tools dynamically without custom API wrappers. |
| *"Implemented secure authentication using JWT and scrypt"* | Custom cryptographic auth in `src/lib/auth.ts` with random salts, scrypt key derivation, and HttpOnly cookies. | *"Why did you use scrypt instead of bcrypt or md5?"* | Explain that scrypt is a memory-hard password derivation function that offers superior resistance to hardware/GPU brute-force attacks compared to MD5 or SHA256. |
| *"Engineered real-time streaming with Server-Sent Events"* | SSE route handler in `src/app/api/agent/stream/route.ts` with `TextDecoder` reader in `src/hooks/useChat.ts`. | *"Why did you choose SSE over WebSockets for AI chat streaming?"* | Explain that LLM streaming is strictly unidirectional (server to client), so lightweight HTTP SSE provides native connection recovery and eliminates WebSocket handshake overhead. |
